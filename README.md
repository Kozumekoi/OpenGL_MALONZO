# OpenGL_MALONZO

OpenGL and FreeGLUT laboratory exercises for CS0045, configured for Visual Studio Code on Linux Mint.

## Requirements

```bash
sudo apt update
sudo apt install -y build-essential gdb freeglut3-dev
```

Install Microsoft's **C/C++** extension (`ms-vscode.cpptools`) in Visual Studio Code.

## Build and run

1. Open this repository's root folder in Visual Studio Code.
2. Open the C++ source file you want to run.
3. Press `Ctrl+Shift+B` to build it.
4. Press `F5` to build and run it with GDB.

The shared build and debug configuration is stored in `.vscode/`.
